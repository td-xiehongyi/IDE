## 已实现

- 扫描完成后自动进入当前目录的分页文件浏览，默认每页 50 条；
- 名称/路径搜索、扩展名/大小/修改时间筛选和多字段排序；
- 名称和路径采用 Unicode 规范化后的大小写不敏感匹配；
- 基于 `notify` 的新增、修改、重命名、删除及目录子树事件索引同步；
- 监听边界复核，不跟随符号链接或 Junction 越出授权目录；
- 索引变化后刷新当前查询并显示变化提示，应用重启后仍可查询最近索引。

## 已有自动化证据

- `FileBrowser.test.tsx` 覆盖自动浏览、搜索防抖、筛选排序分页、空结果、错误状态和监听刷新；
- `App.test.tsx` 覆盖阶段三界面及后续阶段入口隔离；
- `search_integration.rs` 覆盖 Unicode/Windows 路径、大小写不敏感搜索、筛选、排序和分页边界；
- `watcher_integration.rs` 覆盖新增、修改、重命名、删除同步以及链接和越界事件隔离。
