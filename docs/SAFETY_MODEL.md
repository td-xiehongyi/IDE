# 知识库安全与恢复规则

日期：2026-09-06。状态：新首版目标规则已随方案确认；对应能力尚未全部实现。需求见[PRD](PRD.md)，职责见[架构](ARCHITECTURE.md)。本文件是新方案的安全规则来源，不表示修改文档就改变了旧代码。

## 与旧规则的区别

| 旧文件整理/转型规则 | 新首版规则 |
| --- | --- |
| 不删除文件 | 可以提议移入可恢复回收区；Agent 不永久删除 |
| Markdown/TXT 每次手动保存先审批 | 仅 Markdown；人工编辑自动保存，Agent 修改独立审批 |
| 只连接本地 Ollama | 用户选择云端 OpenAI 兼容服务或本地 Ollama |
| 扫描只保存元数据，单次分析正文临时存在 | 知识库可建立本地正文索引；旧单次分析仍按原数据流理解 |
| 所有“覆盖”均禁止 | 用户编辑可安全更新同一笔记；不得覆盖他人/外部新版本或同名目标 |
| 多根知识空间、旧阶段固定顺序 | 首版默认一个本地文件夹为当前知识库，可切换，按新路线图推进 |

旧实现的计划有效期、接口和测试约束保留在[历史资料](history/README.md)，不能把旧规划重新作为新产品审批要求，也不能让新需求替未完成的执行安全实现背书。

## 目录、内容与权限

- 只访问当前用户打开的知识库；任务限定文件夹或笔记时，所有搜索与读取服从该更小范围。
- 范围限制也作用于维护提案；若引用修复需要超出所选范围，提示用户扩大范围或调整任务，不暗中扩大。
- 不跟随符号链接、Junction 或重解析点跨越授权边界；按 Windows 文件系统语义校验路径，不能只比较字符串前缀。
- 首版 Agent 只处理 Markdown 普通文件，非 Markdown 保持原样。不得访问其他库、应用凭据和恢复数据作为模型上下文。
- 首版无 Shell、程序执行、桌面控制或网页搜索工具；模型服务网络调用与网页搜索是不同能力。
- 首版允许通过专用操作在知识库内新建文件夹，以及移动/重命名单篇笔记（D23）；整目录改名、移动和删除不在范围内。路径输入不能隐式授权创建任意祖先目录；Agent 涉及新建目录时须明确列入审批提案。

## 人工编辑与自动保存

人工编辑通过窄化保存接口执行，不要求每次预览审批。读取时记录基线版本，保存前复核当前文件；外部变化不能被自动覆盖。保存失败保留编辑内容并显示真实状态。历史版本持久成功和安全写入必须协调，失败不得把尚未完成的保存显示为已完成。

人工恢复历史须显式选择、查看影响并确认。即时预览渲染不执行笔记内脚本；远程资源不能仅因打开笔记就静默发送资料。

## Agent 提案与确认

1. 模型调用受限工具形成提案，Rust 校验路径、类型、内容版本、目标冲突和所有依赖。
2. 一组预览包含所有相关文件的差异、名称/位置变化与删除项。用户可逐文件查看，整组确认或取消。
3. 确认绑定后端不可变提案，不能由前端提交替换后的内容，不能由模型调用执行或模拟批准。
4. 确认只覆盖当前计划；新增修改、计划过期、取消或基线变化后重新预览。提案一次性消费，不可重放。
5. 确认时和执行各项前复核磁盘，运行中首个失败后停止尚未开始的项目；记录成功、失败、未执行和中断状态。

审批凭据只由后端与直接响应用户动作的界面处理，不进入模型、日志或通用工具结果。笔记中的“忽略规则”等文字是资料，不是控制指令。工具输入需结构校验，不能以模型输出可信为由绕过后端策略。

## 历史、回收与任务回退

- 新建、修改、重命名、移动和删除按任务记录；删除必须先建立可验证的恢复内容与记录，再移除正式位置的笔记。
- 回收不是无保护的跨卷移动捷径。恢复区与知识库位于不同卷时，需要专门的持久化、校验和中断恢复实现；未验证前不得启用删除。
- 多文件执行没有数据库事务式原子性。发生失败不自动声称全组未变，也不进行可能覆盖新内容的静默补偿。
- 回退只处理实际成功项，并验证当前版本和路径占用。后续编辑、目标占用、缺失、权限变化均可阻止自动恢复；保留冲突信息供用户处理。
- 历史恢复和任务回退自身也记录结果；清理索引不得删除恢复数据。
- 历史版本默认长期保留，由用户手动清理（D19），不自动按时间或空间淘汰。清理的影响预览、空间提示与任务回退依赖处理在第一阶段设计中细化；永久清空回收区尚未授权。

## AI 与隐私

用户选择云端或本地 Provider。默认不在本地失败后自动外发到云端；切换服务需可见。云端只发送完成当前任务所需内容，不能默认上传整个库；本地检索与监听不自动调用模型。

API 密钥进入 Windows 系统凭据存储，不进知识库、前端持久存储、版本快照、日志或模型上下文。应用索引与历史在本地按库隔离，恢复快照可能包含正文。诊断日志不保存完整正文或密钥；任务记录只保存必要状态与变化证据，不保存模型隐藏推理。对话持久化与清理策略在 AI 阶段明确。

模型不支持工具调用、连接失败、超时、取消或预算耗尽须返回真实状态。引用仅指向实际读取/检索且在当前任务范围内的来源，不凭模型编造路径；版本变化时提示重新核对。

## 必须验证

验证授权边界与重解析点、中文编辑和自动保存冲突、伪造/重复/过期审批、确认前零写入、取消与中断、部分失败、引用修复、回收完整性、回退冲突、索引重建不清理历史、密钥不落笔记/日志、笔记提示注入与模型能力不足。使用隔离副本；功能、桌面集成和恢复证据分别记录。
