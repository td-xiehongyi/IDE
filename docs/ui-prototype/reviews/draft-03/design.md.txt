## draft-03 修订与本轮检查

用户要求将文件和文件夹的新增入口统一到“对目标文件夹或空白区域右击”。本轮隐藏左侧“＋笔记 / ＋文件夹”、快捷栏新建按钮和标签栏新建按钮；右击文件夹、文件夹内笔记或目录空白区域打开统一菜单，提供“新建 Markdown 笔记”和“新建文件夹”。右击笔记时把其父目录作为目标，空白区域使用知识库根目录。

原型中新增笔记会进入右击时选定的目标文件夹；新增文件夹当前模拟为知识库根目录下的单层目录，嵌套文件夹行为留给正式文件树设计确认。右键菜单是本轮新增交互，保留 draft-02 作为不可覆盖的评审基准。

## draft-02 修订与本轮检查

用户要求：“左侧的目录和中间的区域暂时做成和obsidian一样，右侧留出空间给agent”。本轮采用 Obsidian 式左侧快捷栏、紧凑目录树、底部知识库名和中间笔记标签页；改为中性灰白与紫色强调。右侧替换为独立 Agent 面板，包含任务建议和输入区域，不再被反向链接及说明卡片占用，也不再随窄窗口自动隐藏。

结构参考：[Obsidian 官方工作区说明](https://obsidian.md/help/workspace)。没有用户指定的 Obsidian 版本、主题或截图，本轮是布局与默认风格靠拢，不宣称像素级复刻或完整功能兼容。标签页可切换，暂不演示关闭/拖动/分组；目录可折叠，新建笔记/文件夹沿用模拟流程。

本轮在内置浏览器实际打开并截图检查，页面报告视口 796×728 CSS 像素，页面 scrollWidth=796，无整体水平溢出，Agent 面板可见。脚本语法检查通过；本轮未复跑全部 draft-01 交互测试。Agent 提示词只填入演示输入框，发送只显示未接入说明，不调用模型。字体与浏览器版本限制沿用下文。

## 目标与默认风格

探索方案：面向个人日常写作，以笔记内容为中心，左侧导航、中间编辑、宽屏右侧笔记联系；暖白背景与低饱和绿色为未确认视觉默认。沿用已有工作台的分区思路，但不把旧截图当作本轮已确认设计。

1024 CSS 像素宽度下隐藏右侧辅助区，保留编辑与导航，状态菜单仍可打开。窄窗口不是手机端承诺。样式变量集中在 HTML 的 :root；使用系统字体，无远程字体或图片资源。

## 可体验流程

- 点击段落进入 Markdown 原文编辑，离开段落显示简化排版；源码按钮编辑整篇内容，再切回即时预览。
- 编辑后切换另一篇，再返回查看版本历史；检查点演示按钮模拟 5 分钟触发，未变内容不重复记录。
- 点击“复习指南”出现同名选择，选择后改成明确路径并跳转；唯一名称直接打开。
- 新建演示笔记/文件夹、按名称搜索；版本历史可查看当前与待恢复内容，确认恢复。
- “状态”菜单可切换正常、保存失败、外部冲突、加载中和空状态；失败/冲突阻止切换，回到正常后可继续。重置恢复初始虚构数据。

## 模拟边界

所有数据仅在页面内存中，刷新后丢弃。不读取真实文件夹、不写磁盘、不使用持久化存储、不连接 AI。即时预览使用简化段落编辑演示，不是 CodeMirror 集成：不据此确认真实 IME、撤销历史保持、完整 Markdown 解析或编辑器选型。表格、改名/移动、回收、手动清理和真实关闭恢复未演示。

错误状态由菜单切换，不能证明后端冲突协议有效。5 分钟周期可用按钮模拟，本轮未等待完整周期。反向链接是简化模拟，仅展示能唯一解析的引用；不是完整链接索引。

## 检查证据

环境：Codex 内置浏览器；浏览器构建版本及 Windows 显示缩放未单独读取。页面报告 devicePixelRatio 约 1.2，实测 CSS 视口 1200×750、1024×750；两者 document.scrollWidth 与 innerWidth 相等，无页面水平溢出。1024 下读取样式确认右侧辅助区隐藏，状态菜单仍可用。使用系统字体，中文可见；未验证字体在其他机器上的回退效果。

已通过浏览器操作观察：源码编辑中文内容后切换笔记生成检查点、查看历史、同名链接选择与跳转、模拟外部冲突和保存失败阻止切换、新建文件夹显示、点击标题进入段落编辑。已检查截图和 DOM；截图工具的捕获尺寸与页面视口不完全一致，因此截图不作为像素级验收依据，本轮未保存截图文件。

脚本语法检查通过。保存/历史与链接路径有交互检查，但未做真实中文输入法组合测试、跨模式撤销测试或文件系统测试；恢复确认按钮的完整路径留给用户体验及后续补测，不宣称已验证。

## 评审任务与验收

1. 给定初始笔记 → 点击段落修改 → 切换源码 → 检查内容是否便于编辑与核对。
2. 给定两篇同名笔记 → 点击链接 → 选择路径 → 检查选择方式是否清楚。
3. 修改后切走再回来 → 查看历史 → 查看旧内容 → 检查恢复预览是否易懂。
4. 打开状态菜单 → 切换失败/冲突 → 尝试切换 → 应保留当前内容并给出提示。
