# 阶段验收资料

每个阶段只保存从该阶段真实可运行版本取得的资料。不得为了补齐截图而提前实现未来功能或制作临时产品入口。

## 通用记录要求

每个阶段的 `README.md` 必须记录：

- 验收状态；
- 截图或证据生成日期；
- 对应 Git 提交；
- 已实现功能；
- 明确未实现的功能；
- 截图、测试报告或其他证据清单。

未完成验收时保留“待验收时填写”，不能预填日期、提交号或虚构证据。

## 目录

- `phase-01/`：项目基础和初始首页；
- `phase-02/`：目录选择、扫描进度和结果摘要；
- `phase-03/`：文件浏览、搜索筛选和文件变化更新；
- `phase-04/`：安全操作管线的自动化测试证据；
- `phase-05/`：AI 建议与完整用户流程的真实截图；
- `phase-06/`：构建、安装、升级和安全检查证据。
