# 阶段六设计：IDE 式知识工作台 UI

| 属性 | 值 |
| --- | --- |
| 状态 | 设计完成；未实现 |
| 目标版本 | `v0.2.0` |
| 最后更新 | `2026-08-23` |
| 依赖 | 阶段一至四已实现能力；阶段五内部开发版；[转型总设计](./superpowers/specs/2026-08-23-ai-knowledge-agent-transformation-design.md) |

## 目标

- 将当前纵向堆叠页面迁移为顶部、左侧、中间、右侧和底部组成的 IDE 式工作台。
- 在不改变现有 Rust 安全接口的前提下，拆分 `FilesFeature` 的扫描、浏览、操作、AI、历史和错误状态职责。
- 为知识空间、文档阅读、引用定位、编辑差异和 Agent 审批提供稳定交互骨架。
- 保持扫描、搜索、AI 分析、安全移动/重命名、历史和撤销在迁移过程中可访问。

## 非目标

- 本阶段不实现知识文本块、向量索引、RAG、文档写入或 Agent。
- 不改变阶段四 `planId` 管线，不增加通用 Tauri 调用器或直接文件访问。
- 不在文件树中加入删除、覆盖、目录移动或任意目录创建。
- 不为了窄窗口把三栏垂直堆叠成移动端页面。

## 用户流程与布局

```text
顶部：知识空间占位入口 / 全局搜索 / Ollama 状态 / 设置
左侧：授权根目录与文件树
中间：文档标签页 / 阅读器占位 / 操作预览
右侧：Ask / Agent 统一助理面板
底部：索引 / 监听 / 模型 / 后台任务 / 历史
```

桌面默认左侧 260px（可调 220–480px），右侧 360px（可调 320–560px），中间占据剩余空间。最小推荐窗口为 1100×700；低于 1100px 时右侧折叠为抽屉，左侧可折叠为图标栏，中间始终为主区域。尺寸与折叠状态按知识空间保存；知识空间在本阶段可先由现有授权根目录兼容适配。

## 前端领域与状态

```text
app-shell / workspaces / explorer / documents / search / operations
assistant / agent / approvals / activity / settings
```

- `WorkspaceSession`：当前工作区标识、授权根目录和恢复状态。
- `ExplorerState`：展开节点、选择集合、过滤条件和快速定位。
- `DocumentSession`：标签页、活动文档、临时预览、固定状态和草稿占位。
- `AssistantSession`：面板模式、上下文范围、消息和引用占位。
- `AgentSession`：运行与审批占位状态；本阶段不执行 Agent。
- `ActivityState`：扫描、监听、AI 分析和文件操作后台状态。

业务持久状态仍通过 Rust/SQLite 管理。面板尺寸、折叠和最近标签可作为 UI 会话状态保存，但不得包含正文或执行凭据。

## 文件树行为

- 第一版只显示一个活动授权根目录；选择新根目录会切换工作区并清理旧选择、标签、AI 结果和操作预览。目录子节点按展开动作从 SQLite 索引懒加载。
- 支持文件名过滤、快速定位、单选、Ctrl 多选和 Shift 范围选择。
- 单击文件打开临时预览标签；双击或开始编辑后固定标签。
- 右键菜单仅提供打开、在资源管理器中显示、请求 AI 分析、重命名和移动。
- 移动与重命名继续进入阶段四 From/To 预览确认管线。
- 展示未索引、索引中、索引失败和内容过期状态；阶段七实现前可显示为兼容占位。
- 符号链接和 Junction 使用独立图标，不允许越界展开。

“在资源管理器中显示”必须使用专用、平台限定且经过授权复核的后端入口；不能转化为任意 Shell 命令。如果该入口尚未设计完成，菜单项保持禁用并说明原因。

## 文档工作区接口

```ts
type DocumentLocation = {
  headingPath?: string[];
  pageNumber?: number;
  lineStart?: number;
  lineEnd?: number;
  characterStart?: number;
  characterEnd?: number;
};

type DocumentViewerKind =
  | "markdown"
  | "text"
  | "code"
  | "pdf"
  | "docx"
  | "unsupported";
```

阶段六只实现元数据查看器：显示真实索引中的文件名、路径、格式、大小和修改时间，并明确提示正文查看尚未启用，不读取或伪造正文。Markdown/TXT 写入属于阶段九，正文阅读接口在后续阶段单独设计。

- 最多恢复最近 20 个标签。
- 切换知识空间前必须处理未保存草稿；阶段九前不产生可保存草稿。
- 文件失效时保留标签并展示失效状态，不静默关闭或打开同路径新文件。
- PDF 目标能力为分页、缩放、文本选择、页内搜索和引用跳页；DOCX 为结构化只读预览。
- 不支持格式只显示文件信息和原因，不尝试错误解析。

## 统一助理面板

模式固定为 `Ask`、`Agent`。`Ask` 在阶段八问答后端实现前明确标为未启用；`Agent` 在阶段六直接承载现有受控 AI 分析与整理建议，但它只能生成建议和现有 `OperationDraft`，不代表阶段十自主 Agent 已实现。

`Agent` 的上下文采用“选中优先，否则当前文档”：存在多选普通文件时使用多选集合，否则使用当前活动普通文件；`KnowledgeSpace` 在阶段六保持禁用。

上下文范围控件始终可见：`CurrentDocument`、`SelectedDocuments`、`KnowledgeSpace`。默认是当前文档，扩大范围必须由用户主动选择。阶段八实现前只保存交互选择，不发起 RAG。

写操作审批摘要位于右侧，完整差异或路径预览位于中间。需要处理的冲突进入审批中心；普通错误留在所属面板，不依赖会自动消失的通知。

## 键盘与可访问性

| 快捷键 | 行为 |
| --- | --- |
| `Ctrl+P` | 快速打开文件 |
| `Ctrl+Shift+F` | 搜索当前知识空间 |
| `Ctrl+S` | 保存当前 Markdown/TXT；阶段九前提示功能未启用 |
| `Ctrl+W` | 关闭当前标签 |
| `Ctrl+Tab` | 切换标签 |
| `Ctrl+Shift+A` | 聚焦 AI 输入框 |
| `Escape` | 关闭抽屉或取消当前临时操作 |

文件树、标签、范围选择、引用和审批必须可通过键盘操作，并有清晰焦点、选中、禁用和错误状态。

## 错误与安全

- 切换根目录、刷新索引或文件变化时，当前选择、预览和过期 AI 结果必须重新校验。
- UI 不缓存或展示可由用户编辑的 `planId`；确认仍通过现有窄化接口。
- 窄窗口折叠不能隐藏待审批写操作或未保存状态，应在入口显示持久标记。
- 预览加载失败时不得记录 AI 建议已采用。
- AI/模型不可用只影响助理区，文件树、文档查看和手动操作继续工作。

## 迁移顺序

1. 建立 `AppShell`、三栏与底部工具窗口。
2. 通过兼容适配层迁移现有文件浏览与搜索。
3. 将详情与阅读器占位迁入中间标签区。
4. 将现有 `AiPanel` 能力拆入统一助理面板的 `Agent` 模式。
5. 将操作预览迁入中间，将历史迁入底部。
6. 每迁移一个入口即补充回归测试，最后才删除旧页面组合。

## 测试矩阵

- 布局：默认宽度、拖拽上下限、低于 1100px 抽屉行为和中间主区域。
- 状态：根目录切换、选择同步、活动文档、最多 20 个标签与无效文件恢复。
- 文件树：懒加载、过滤、Ctrl/Shift 多选、链接不可越界展开和上下文菜单权限。
- 助理：`Ask / Agent` 两种模式、选中优先上下文、知识空间范围禁用、不可用能力明确禁用。
- 操作：现有移动/重命名预览、确认、历史与撤销从新入口完整可用。
- 键盘：全部固定快捷键、焦点顺序、Escape 取消和抽屉关闭。
- 回归：扫描、分页搜索、监听、阶段四操作与阶段五内部 AI 流程行为不变。

## 验收门槛

- 现有扫描、浏览、搜索、AI 分析、安全移动/重命名、历史和撤销均可从新工作台进入。
- 三栏之间的选中文件、活动文档、AI 上下文与操作预览同步正确。
- 后端安全接口未扩宽，前端没有直接文件系统、SQLite、Ollama 或 Shell 调用。
- 键盘和窄窗口行为通过组件测试，待审批与错误状态不会因折叠丢失。

## 已知限制

- 本阶段不承诺完整 PDF/DOCX 渲染质量；适配器可先以只读最小能力交付。
- 知识索引状态、引用和 Agent 面板在阶段七至十实现前只能显示真实的未启用状态。
- 面板会话恢复格式需在知识空间持久化模型确定后最终锁定。
