# 个人知识库系统架构

日期：2026-09-06。状态：已确认方向下的目标架构；未实现部分明确标注。需求见[PRD](PRD.md)，规范性写入规则见[安全模型](SAFETY_MODEL.md)。

## 现有基础与迁移策略

沿用 Tauri 2 + React/TypeScript + Rust + SQLite，渐进改造，不重建一套平行应用。实际依赖以 package.json 与 src-tauri/Cargo.toml 为准。

现有 App 已挂载 Workbench。Rust 注册扫描、元数据搜索、Explorer、受控文件操作和旧 AI 分析入口；现有正文提取、路径策略、监听、历史仓储可作为复用候选。Workbench 的正文、Ask 和 Agent 仍未启用。代码存在与真实桌面验收是不同证据，本轮只做静态核对。

原分类模板、分类分析和多格式提取是旧业务，不作为知识库 Agent 的控制中心。逐项复用底层能力，不直接扩张旧分类接口承担编辑/聊天。保留当前未提交代码；后续迁移必须兼容已有数据库和操作历史，不删除数据库重建。旧详细架构与原状态记录见[历史入口](history/README.md)。

## 职责与依赖

```text
React 工作台、编辑器、链接导航、助理和变更预览
        ↓ 窄化 Tauri 请求
Rust 知识库 / 文档 / 索引 / 任务 / 变更服务
        ↓
领域规则与路径、冲突、审批校验
        ↓
文件系统、SQLite 仓储、凭据存储、模型 Provider
```

前端不直接访问文件系统、数据库或模型密钥。Agent 使用受限工具，不获得文件执行器或数据库连接。用户确认由独立界面经后端绑定当前提案，不能由模型生成确认。

| 模块（目标职责，不是已存在目录承诺） | 责任 |
| --- | --- |
| 知识库 | 打开/切换一个本地根目录、授权范围、监听生命周期与库隔离 |
| 文档与编辑 | Markdown 原文、即时预览/源码状态、自动保存、版本检测、链接导航 |
| 索引 | 正文、位置、内容版本、出入链接与搜索；增量更新、重建与错误状态 |
| 检索与回答 | 任务范围、候选片段、读取当前正文、引用验证与证据不足表达 |
| 模型接入 | OpenAI 兼容云端和 Ollama 适配、凭据引用、取消、超时和能力检测 |
| Agent 任务 | 根据结果迭代调用库内工具，受步数/时间预算约束，生成提案或答案 |
| 变更与恢复 | 提案预检、不可变预览、一次性确认、逐项执行、日志和恢复冲突 |

Markdown 源码为权威内容，编辑器必须能往返保存而不无故重排未编辑部分。不指定未经验证的编辑器库；在中文输入、选区、源码切换和大笔记验证后锁定依赖。

## 数据与接口方向

正式笔记留在知识库中。应用数据区保存按知识库隔离的派生索引、恢复数据和任务元数据；密钥使用 Windows 系统凭据存储。索引可清理重建，版本与回收内容不能当缓存删除。恢复数据可能包含完整笔记，不能声称它只有元数据。

下列是后续接口设计的责任范围，不是已注册 Command 或最终命名：

- 知识库打开/切换、列目录、读取笔记、查询链接。
- 人工保存：知识库标识、笔记标识、已读内容版本、新内容 → 新版本或冲突/失败；不复用 Agent 审批作为每次自动保存前置。
- 搜索：知识库标识、可选文件夹/笔记范围、查询 → 带文档位置与版本的结果。名称检索和正文检索分别区分。
- 任务开始/取消/状态：绑定知识库、范围和 Provider；切库不能把旧任务结果写进新库。
- 提案预览/确认/取消：预览包含内容差异、路径变化和删除项；确认只引用当前后端提案，不携带可替换的操作内容。
- 历史查询/恢复预览/确认：恢复前验证当前状态，不能把历史记录存在当成必然可回退。

文档版本、范围与来源必须贯穿检索、提案和执行。索引中的旧内容不能作为执行前最新文件状态。更具体的序列化结构在相应阶段设计中确定，避免按旧阶段九的 editPlanId 为所有人工保存强制审批。

## 关键数据流

人工编辑 → 带基线版本的保存 → 复核磁盘 → 持久恢复数据 → 安全写入 → 更新版本与索引。中文输入组合期间不得因自动保存破坏编辑；保存失败保留用户内容。

链接索引从 Markdown 内容构建。重命名/移动先收集受影响引用，再以一组变更更新笔记与引用。重名、相对路径、别名、标题定位和断链行为需在第一阶段确定，不默认完整兼容 Obsidian。

Agent 输入 → 范围内搜索/读取 → 模型输出答案或提案 → Rust 校验 → 用户逐文件查看/整组确认 → 再次复核 → 逐项执行并记录 → 增量更新索引。模型不接触确认凭据。

恢复读取独立历史，验证目标与后续编辑后生成恢复预览；执行中断可依据持久状态辨明已经成功的项目，不声称多文件原子性。

## 检索与 AI

几百篇规模先使用本进程与 SQLite 管理索引，不部署独立向量数据库服务。全文检索需针对中文、标题、精确词和同义表达验证；不能把默认分词器当作已解决中文召回。语义检索是否加入由样本评测决定，旧 sqlite-vec 与嵌入模型候选不再是强制依赖。

云端和本地共享任务工具语义，不假定所有 OpenAI 兼容服务或 Ollama 模型都支持相同工具调用/结构输出。调用不支持时显示能力限制，不伪造 Agent 完成。模型服务请求属于 AI 连接，库内 Agent 首版无独立网页、Shell 或桌面控制工具。
