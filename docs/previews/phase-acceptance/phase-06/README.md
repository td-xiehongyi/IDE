# 阶段六工作台验收基线

阶段六以 Codex 浅色交互原型作为视觉与交互参考，但生产代码必须使用 React、真实状态和窄化 Tauri 接口，不得导入原型脚本或模拟数据。

## 组件映射

| 原型区域 | React 责任 | 真实数据来源 |
| --- | --- | --- |
| Top Bar | 文件菜单、快速打开、模型状态、面板按钮 | dialog 插件、搜索接口、AI Provider 状态 |
| Explorer | 单活动根、懒加载目录树、选择 | SQLite 文件索引只读查询 |
| Document | 标签、元数据查看器、操作预览 | 索引条目、阶段四操作预览 |
| Assistant | Ask 未启用、Agent 整理建议 | 阶段五 AI 接口 |
| Activity | 索引、监听、模型、任务、历史 | 扫描事件、监听事件、AI 状态、操作历史 |
| Status Bar | 当前根、索引和安全状态 | 工作台会话状态 |

## 固定视觉变量

- 浅色主题；JetBrains Mono 全局字体。
- 顶栏 48px，活动窗口 180px，状态栏 24px。
- Explorer 默认 260px、限制 220–480px；Assistant 默认 360px、限制 320–560px。
- 画布 `#f8fafc`，面板 `#ffffff`，强调色 `#087f5b`。
- 1100px 以下 Explorer 折叠为图标栏，Assistant 变为抽屉，中间区域保持主区域。
